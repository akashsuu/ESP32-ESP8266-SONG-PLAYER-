# RF24 requirement for ESP8266 core 2.5.0

Import [`RF24-1.4.6-ESP8266-2.5.0.zip`](RF24-1.4.6-ESP8266-2.5.0.zip) for this
receiver. It is RF24 by TMRh20 v1.4.6 with one ESP8266-core-2.5.0-only
compatibility change already applied.

RF24 releases before 1.4.6 call the ESP8266 2.5.0 `pgm_read_ptr()` macro in a
way that fails to compile with:

```text
'const void*' is not a pointer-to-object type
```

The RF24 upstream project fixed that exact problem in v1.4.6 (pull request
#864). The fix is in RF24 diagnostic implementations such as `printDetails()`,
`printPrettyDetails()`, and `sprintfPrettyDetails()`; it does not change radio
transmission, reception, packet contents, SPI configuration, auto-ACK, or ACK
payload behavior.

The receiver does not call any of the diagnostic functions.

## Arduino Web Editor

1. Download the included `RF24-1.4.6-ESP8266-2.5.0.zip` file.
2. In Arduino Web Editor, open the Libraries panel and use **Import library**
   to upload that ZIP.
3. Remove/disable any older RF24 copy associated with the sketch, then compile.

The imported library overrides `pgm_read_ptr()` only when
`ARDUINO_ARCH_ESP8266` is defined. It changes only diagnostic PROGMEM pointer
handling, not RF24's SPI/radio behavior, and does not affect AVR or ESP32.
